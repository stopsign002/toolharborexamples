Hello Static

This page is a ToolHarbor static tool. It is served under whatever path the portal mounts it at (normally /t/hello-static/) and every URL on this page — the script and every fetch below — is written relative to this document, with no leading slash. The one exception is the stylesheet above: /toolkit/toolharbor.css is one of the two absolute paths every tool is allowed to use (the other is /api/...) — see docs/TOOL-AUTHORING.md §4 and §19 in the portal repo for why a plain /x URL breaks the moment a tool is installed, and why the kit stylesheet is the exception.

1. Tool store round-trip

Saves and loads a note through the portal's per-tool key/value store (GET|PUT /_store/:key) — no SQL needed for something this small.

    https://httpbin.org/get?x=1 with the X-Demo-Key
    header injected server-side from this tool's DEMO_KEY
    setting. The key is never sent to this page — httpbin echoing it back
