Hello Static

This page is a Toolhub static tool. It is served under whatever path the portal mounts it at (normally /t/hello-static/) and every URL on this page — the stylesheet, the script, every fetch below — is written relative to this document, with no leading slash. That is rule #1 for every tool: see docs/TOOL-AUTHORING.md in the portal repo for why an absolute /x URL breaks the moment a tool is installed.

1. Tool store round-trip

Saves and loads a note through the portal's per-tool key/value store (GET|PUT /_store/:key) — no SQL needed for something this small.


  


  

    
2. Declared upstream

    
Calls ./_up/echo/get?x=1, which the gateway proxies to
    https://httpbin.org/get?x=1 with the X-Demo-Key
    header injected server-side from this tool's DEMO_KEY
    setting. The key is never sent to this page — httpbin echoing it back
    in the JSON below is the proof the header was added upstream, not here.
